# Báo cáo: Ứng dụng Google Dorking để tìm kiếm tài liệu chính thống

## 1. Truy vấn mẫu (Search Query)
```text
"Nhập môn Công nghệ Thông tin" site:ptit.edu.vn filetype:pdf -123docz.net -tailieu.vn
```

## 2. Phân tích hiệu quả kỹ thuật
- **Độ chính xác:** Loại bỏ hoàn toàn các trang SEO rác (`-123docz.net`, `-tailieu.vn`).
- **Nguồn tài liệu:** Giới hạn trực tiếp trên máy chủ giáo dục (`site:ptit.edu.vn`).
- **Tối ưu thời gian:** Lọc trực tiếp định dạng tài liệu (`filetype:pdf`), tải ngay lập tức và tránh nguy cơ lây nhiễm mã độc từ các liên kết chuyển hướng.
